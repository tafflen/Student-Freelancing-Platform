# STUDENT FREELANCING PLATFORM

A beginner-friendly, full-stack MERN (MongoDB, Express.js, React, Node.js) web application.

---

## 1. PROJECT OBJECTIVE

The **Student Freelancing Platform** connects college students who offer freelance services with clients such as early-stage startups, small businesses, student clubs, and individuals looking for affordable digital services.

Students can offer services such as Graphic Design, Web Development, Content Writing, Presentation Design, and Video Editing. Clients can browse available services, search for suitable services, view service details, and submit service requests.

Freelancers can create and manage their service listings and handle requests received from clients by accepting or rejecting them. Clients can track the status of their submitted requests.

The main objective of the project is to provide a simple platform where students can gain practical freelance experience while clients can find affordable student-provided services.

---

## 2. PROJECT FEATURES

- User registration and login
- Freelancer and Client roles
- Freelancer service creation
- View available services
- Search services
- Filter services by category
- View complete service details
- Edit freelancer's own services
- Delete freelancer's own services
- Send service requests
- View received requests
- Accept or reject requests
- View sent requests
- Track request status
- MongoDB database storage
- REST API based frontend-backend communication

---

## 3. USER ROLES

| Role | Permissions & Capabilities |
| :--- | :--- |
| **Freelancer** | • Create new service offerings with price, category, and description.<br>• View, edit, and delete their own services.<br>• View incoming client requests.<br>• Accept or Reject requests with "Pending" status. |
| **Client** | • Browse student freelance services.<br>• Search and filter services by keyword and category.<br>• View complete service and freelancer details.<br>• Send service requests with project requirements.<br>• Track request status ("Pending", "Accepted", "Rejected"). |
